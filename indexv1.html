** WHAT IS IRC? **

IRC (Internet Relay Chat) is the ORIGINAL online chat protocol - long before all these fancy web messengers came along. AtomNet is the official chat network of The Atomic Corporation. Load up an IRC client, point it at our server, and you will be chatting with fellow atoms in seconds. No registration, no phone number, just pure text-based COMMUNITY.

** HOW TO CONNECT TO ATOMNET **

Fire up your IRC client of choice and connect to:

SERVER PORT ENCRYPTION DESCRIPTION
irc.atomnet.org 6667 none standard (recommended)
irc.atomnet.org 6697 SSL/TLS secure - use it!
irc.atomnet.org 7000 none backup port

Once connected, type /join #atomnet to enter the main hall. Simple as that!

Quick connect for common clients:

CLIENT COMMANDS
mIRC (Windows) /server irc.atomnet.org:6667
/join #atomnet
HexChat (Win/Linux) /connect irc.atomnet.org
/join #atomnet
irssi (Linux/UNIX) /server add -auto -network AtomNet irc.atomnet.org 6697
/connect AtomNet
/join #atomnet
weechat (Linux/UNIX) /server add atomnet irc.atomnet.org/6697 -ssl
/connect atomnet
/join #atomnet

No client installed? Download one here (under construction), or use our WEBCHAT - JavaScript not required! (well... maybe a little)
