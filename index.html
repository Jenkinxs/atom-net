Welcome to AtomNet

AtomNet is the internal messaging network of The Atomic Corporation. Built on the Internet Relay Chat protocol (RFC 1459), AtomNet provides real-time text communications for departments, project teams, and operations staff across all corporate facilities.

All authorized personnel may connect using a standard IRC client. Please review the connection specifications below and our communications policies before your first session.



1. Connection Specifications

Connect your IRC client to the following server address:

SERVER PORT ENCRYPTION PURPOSE
irc.atomnet.org 52425 SSL/TLS Primary access

Upon connection, proceed to the main hall with /join #Hub.

2. Approved Client Configuration
CLIENT PLATFORM CONFIGURATION
mIRC - Windows 95/NT 4.0 /server irc.atomnet.org:52425
/join #Hub
HexChat - Windows / Linux /connect irc.atomnet.org
/join #Hub
irssi - UNIX / Linux /server add -auto -network AtomNet irc.atomnet.org 52425
/connect AtomNet
/join #Hub
weechat - UNIX / Linux /server add atomnet irc.atomnet.org/52425 -ssl
/connect atomnet
/join #Hub

Client software is distributed by the Information Systems Division. Personnel without a client may use the web-based console at console.atomnet.org.



3. Corporate Channels

4. Communications Policy (Summary)

1. All communications shall be professional and courteous.
2. Unauthorized automated clients (bots) are prohibited without network operator approval.
3. Channel operators enforce policy; their decisions are final.
4. Personnel may not transmit proprietary or classified information over unencrypted connections.
5. The network is monitored for compliance. Policy violations are reported to the Information Systems Division.

Reference: IS-POL-004 - Electronic Communications Policy
